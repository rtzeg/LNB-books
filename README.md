# LNB Beyond

Discover. Navigate. Understand.

Native offline iOS library companion built with SwiftUI, SceneKit and Swift Charts. Includes 31 demonstration books, an adaptive anonymous survey, local recommendations, audience insights, and fixed book locations inside a schematic Gaismas pils model.

## Run

Open `LibOS.xcodeproj`, select the `LibOS` scheme and an iPhone simulator, then press Run. Requires iOS 17 or later. No API keys, backend or third-party packages are needed.

For a physical iPhone, select your own development team in **Signing & Capabilities**, enable Developer Mode on the phone and choose it as the run destination. The project's existing team setting is specific to the original development environment.
